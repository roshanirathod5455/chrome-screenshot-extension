# Chrome Extension – Full Page Screenshot

## Overview

A Chrome extension that captures screenshots of web pages and downloads them as PNG images.

## Features

* Capture current browser tab
* Download screenshot automatically
* Simple popup UI
* Built using Manifest V3

## Technologies Used

* JavaScript
* HTML
* CSS
* Chrome Extension APIs

## Installation

1. Download project
2. Open Chrome
3. Go to chrome://extensions
4. Enable Developer Mode
5. Click "Load Unpacked"
6. Select project folder

## Usage

* Open any website
* Click extension icon
* Click "Capture Screenshot"
